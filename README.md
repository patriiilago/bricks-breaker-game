# Bricks Breaker Game

**Bricks Breaker** is a modern take on the classic arcade-style game, developed as part of the Ironhack Web Development Bootcamp. This project showcases my skills in front-end development, game logic, and interactive UI design.

## 🎯 Project Overview

In Bricks Breaker, players control a paddle to bounce a ball and break all the bricks on the screen. The ball reacts to collisions with the paddle, walls, and bricks, creating a dynamic and engaging gameplay experience. The game ends when all bricks are destroyed, challenging the player’s reflexes and strategy.  

> ⚠️ Note: This game is designed for desktop use and is not responsive for mobile devices.

## 🛠 Technologies Used

- **HTML5** – Structured the game layout and elements.  
- **CSS3** – Styled the game interface and added animations.  
- **JavaScript** – Implemented game logic, collision detection, and interactive gameplay.  

## 🕹 Game Objective

- Control the paddle using the keyboard.  
- Break all bricks on the screen to win.  
- Avoid letting the ball fall below the paddle.  

## 🚀 Demo

Play the live version of the game [here](https://bricks-breaker-pcgame.netlify.app/).  

## 💡 Key Features

- Keyboard-controlled paddle for precise gameplay.  
- Dynamic collision detection for bricks, walls, and paddle.  
- Score tracking and game-over condition.  
- Classic retro arcade feel with smooth gameplay.
